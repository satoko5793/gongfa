- [x] 运行环境已正确提供 `JWT_SECRET`，注册/登录不会因签发 token 失败
- [ ] 环境变量已区分本地、生产，未硬编码测试地址

## 7. 建议的人工验收顺序

1. 访问首页，确认商品列表加载。
2. 注册新账号并登录。
3. 管理员后台给测试账号加额度。
4. 用户下单一个有库存的商品。
5. 用户提交取消申请。
6. 管理员审核取消，确认额度回退。
